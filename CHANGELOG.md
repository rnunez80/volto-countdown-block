# Changelog

All notable changes to `volto-countdown-block` will be documented in this file.

## [0.2.0] - 2026-10-24

### Bug Fixes & Compatibility
- **Volto 19 Compatibility:** Updated `peerDependencies` to support `@plone/volto` 17, 18, and 19 (`>=17.0.0 || >=18.0.0-alpha.0 || >=19.0.0-alpha.0`).
- **SSR Optimization:** Optimized bundle and loading performance without affecting SSR using `@loadable/component`.
- **Responsive Width:** Adjusted responsive container width and typography on small mobile screens.

## [0.1.1]

### Improvements
- Initial countdown timer display fixes and lazy loading.
